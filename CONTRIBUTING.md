# Contributing to SillyTavern Smart Import

First off, thank you for considering contributing! It’s people like you who make the AI roleplay community better for everyone. 🎩

## How Can I Help?

### Reporting Bugs
If you find a bug, please open an **Issue**. Be sure to include:
1. Your SillyTavern client version (e.g., 1.16.0, Staging branch).
2. Your platform (Mobile/Desktop/OS).
3. A clear description of what happened vs. what you expected (e.g., specific metadata that failed to match, or a link that crashed the queue).

### Suggesting Enhancements
Have an idea for a new feature or another platform the duplicate-checker should support?
* Open an **Issue** with the "Enhancement" tag. I’m always open to making "Smart Import" even smarter!

### Pull Requests
If you’ve written a fix or a feature yourself:
1. Fork the repository.
2. Create a new branch for your fix.
3. Submit a Pull Request (PR) to the `main` branch.
4. **Keep it clean:** Please try to match the existing coding style and keep the extension lightweight. Avoid adding bulky external dependencies unless absolutely necessary.

## Style Guide
* Use clear variable names.
* Brush up on the [official SillyTavern Extension Documentation](https://docs.sillytavern.app/for-contributors/writing-extensions/) to ensure your code aligns with standard ST API practices.
* Comment on complex logic so others can follow your train of thought.
* Ensure any UI additions or DOM injections respect SillyTavern's native theme CSS variables (just like our `style.css` does!).
